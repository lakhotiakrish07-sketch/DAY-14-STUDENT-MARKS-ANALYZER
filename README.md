# Student Marks Analyzer 🧮

A simple Python program to analyze student marks.

## 🔹 Features
- Takes marks of multiple students
- Stores marks in a list
- Finds highest marks
- Finds lowest marks
- Calculates average marks

## 🔹 Concepts Used
- Python Lists
- max() function
- min() function
- sum() function
- User Input

## 🔹 How to Run
1. Clone or download the repository
2. Run the Python file
3. Enter number of students
4. Enter marks when asked

## 🔹 Example Output
Marks List: [78, 85, 90]  
Highest Marks: 90  
Lowest Marks: 78  
Average Marks: 84.33

## 🔹 Purpose
This project is made for beginners to practice Python basics and list operations.
